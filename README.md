# ระบบรายรับ–รายจ่าย

เว็บแอปแบบ Static สำหรับบันทึกรายรับ รายจ่าย สาขา และดูยอดคงเหลือ ใช้งานได้ฟรีบน GitHub Pages

## ฟีเจอร์
- เพิ่มรายรับ / รายจ่าย
- ระบุหมวดหมู่และสาขา
- ค้นหาและกรองตามประเภทหรือเดือน
- สรุปรายรับ รายจ่าย และกำไรสุทธิ
- สรุปตามหมวดหมู่
- ส่งออก CSV
- สำรอง / นำเข้าข้อมูล JSON
- เก็บข้อมูลใน LocalStorage ของเบราว์เซอร์

## วิธีขึ้น GitHub Pages

1. สร้าง Repository ใหม่ใน GitHub เช่น `income-expense`
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้เข้า Repository
3. ไปที่ **Settings → Pages**
4. ในส่วน **Build and deployment → Source** เลือก **GitHub Actions**
5. Workflow ใน `.github/workflows/pages.yml` จะ deploy เว็บไซต์ให้อัตโนมัติ
6. เปิดแท็บ **Actions** เพื่อดูสถานะ deploy
7. เมื่อสำเร็จ URL จะอยู่ใน **Settings → Pages**

## ข้อควรทราบ
ข้อมูลถูกเก็บใน LocalStorage ของแต่ละเบราว์เซอร์ จึงไม่ซิงก์ข้ามเครื่องหรือหลายผู้ใช้ หากต้องการระบบล็อกอิน/ฐานข้อมูลออนไลน์ ควรต่อ Firebase, Supabase หรือ backend อื่นในเวอร์ชันถัดไป
